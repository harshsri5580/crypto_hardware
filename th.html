    ดูคำตอบสำหรับคำถามที่พบบ่อยที่สุด

    กำลังคิดที่จะซื้อคริปโตหรือ NFT ใช่หรือไม่? คุณจะต้องมี คริปโตวอลเล็ต

    เมื่อคุณสร้างวอลเล็ต จะมีการสร้างคีย์สองคีย์คือ Private Key และ Public Key วอลเล็ตจะเก็บคีย์ของคุณและทำให้คุณเซ็นธุรกรรม, สร้าง Address ใหม่, เริ่มต้นการโอน, ติดตามยอดคงเหลือในบัญชีพอร์ตโฟลิโอ, จัดการคริปโตของคุณ และโต้ตอบกับ dApps

    คริปโตวอลเล็ตมีหลายรูปแบบ ตั้งแต่ Hardware Wallet เช่น Ledger ไปจนถึงแอปมือถือที่คุณสามารถดาวน์โหลดลงในโทรศัพท์หรือแท็บเล็ตของคุณ

    เมื่อคุณซื้อคริปโต เช่น Bitcoin และ Ethereum คุณจะได้รับคีย์สองคีย์: โดยคีย์หนึ่งเป็น Public Key และอีกคีย์หนึ่งเป็น Private Key

    โดยสามารถเปรียบเทียบ Public Key กับหมายเลขบัญชีธนาคารที่คุณสามารถแชร์กับบุคคลที่สามเพื่อรับคริปโตโดยไม่ต้องกังวลว่าสินทรัพย์ของคุณจะไม่ปลอดภัย

    Private Key ที่ใช้ในการลงชื่อในธุรกรรมและช่วยให้คุณสามารถส่งและรับคริปโต การรักษา Private Key ของคุณให้ปลอดภัยและเป็นความลับเป็นสิ่งสำคัญ หากใครก็ตามสามารถเข้าถึงได้ พวกเขาจะมีสิทธิ์เข้าถึงสินทรัพย์คริปโตใด ๆ ที่เกี่ยวข้องกับคีย์เหล่านั้นด้วย

    คริปโตวอลเล็ตจะเก็บ Private Key ของคุณและช่วยให้คุณสามารถเข้าถึงสินทรัพย์ของคุณได้

    มีคริปโตวอลเล็ตประเภทต่าง ๆ โดยแต่ละประเภทมีข้อดีและข้อเสียของตัวเอง
    Hot Wallet นั้นเชื่อมต่อกับอินเทอร์เน็ต ซึ่งสะดวกต่อการใช้งาน อย่างไรก็ตาม วอลเล็ตเหล่านี้ยังเสี่ยงต่อการถูกโจมตีออนไลน์ Examples include web-based, mobile, and desktop wallets. ส่วน Cold Wallet นั้นจะเก็บ Private Key ไว้แบบออฟไลน์เพื่อให้ห่างจากภัยคุกคามทางออนไลน์ ตัวอย่าง ได้แก่ Paper Wallet และ Hardware Wallet

    ทั้งนี้ยังสามารถแบ่งประเภทวอลเล็ตเป็นแบบดูแลทรัพย์สินด้วยตนเองหรือไม่ใช่แบบดูแลทรัพย์สินด้วยตนเอง ขึ้นอยู่กับว่าใครเป็นผู้ถือ Private Key การเก็บข้อมูลคริปโตของคุณในวอลเล็ตแบบมีผู้รับฝากทรัพย์สิน หมายถึงบุคคลที่สามจะเป็นผู้ควบคุม Private Key ของคุณ รวมถึงสินทรัพย์ของคุณด้วย ในทางกลับกัน วอลเล็ตที่ดูแลทรัพย์สินด้วยตนเองอย่าง Ledger ช่วยให้คุณสามารถเป็นเจ้าของและควบคุมคริปโตของคุณได้อย่างสมบูรณ์

    Hot Wallet จะเก็บ Private Key บนระบบที่เชื่อมต่อกับอินเทอร์เน็ต จึงทำให้เสี่ยงต่อการถูกโจมตีทางออนไลน์ การเก็บคริปโตของคุณไว้ใน Exchange หมายความว่าคุณไม่ได้เป็นเจ้าของหรือสามารถควบคุมคริปโตดังกล่าวได้อย่างแท้จริง หาก Exchange ถูกฟ้องล้มละลายหรือหยุดการถอนเงิน คุณจะสูญเสียการเข้าถึงเงินทุนของคุณทันที

    Hardware Wallet เก็บ Private Key ของคุณไว้แบบออฟไลน์ ซึ่งช่วยให้คุณสามารถควบคุมได้เต็มรูปแบบและมีความปลอดภัยมากขึ้น แม้ว่าคุณจะวาง Hardware Wallet ไว้ผิดที่หรือทำหาย คุณก็ยังสามารถหาวอลเล็ตใหม่และใช้ Secret Recovery Phrase เพื่อเข้าถึงสินทรัพย์ของคุณได้

    พร้อมจะเริ่มต้นหรือยัง? นี่คือขั้นตอนในการรับคริปโตวอลเล็ตของคุณ:

    1. รับ Ledger Hardware Wallet โดยวอลเล็ตจะเก็บ Private Key ของคุณไว้ในสภาพแวดล้อมออฟไลน์ที่ปลอดภัย ทำให้คุณสามารถอุ่นใจและควบคุมสินทรัพย์ของคุณได้อย่างสมบูรณ์ คริปโตวอลเล็ต Ledger ทั้งหมดให้บริการโดยชิป Secure Element ของอุตสาหกรรมชั้นนำ ร่วมกับระบบ OS ที่เป็นกรรมสิทธิ์ของ Ledger ที่ปกป้องคริปโตและ NFT ของคุณจากการแฮ็กที่ซับซ้อน
    2. จับคู่คริปโตวอลเล็ต Ledger ของคุณกับ แอป Ledger Wallet เพื่อจัดการคริปโตของคุณได้อย่างง่าย ๆ ติดตามพอร์ตโฟลิโอของคุณ และเข้าถึงบริการ Web3 ที่หลากหลายได้อย่างปลอดภัย ทั้งหมดอย่างสะดวกสบายในที่เดียว!
    3. เพิ่มคริปโตไปยัง Ledger Wallet ของคุณ Ledger ได้รวมผู้ให้บริการบุคคลที่สามชั้นนำเข้าด้วยกันเพื่อช่วยให้สามารถซื้อ, สวอป, สเตค และจัดการคริปโตผ่านแอป Ledger Wallet ได้ โดยจะมีการส่งคริปโตของคุณไปยัง Ledger Hardware Wallet ของคุณอย่างปลอดภัย
